During my internship at **Amazon Web Services Vietnam Co., Ltd.** from **April 17, 2026** to **July 10, 2026**, I had the opportunity to learn, practice, and apply the knowledge I had gained at school to real-world work, while gradually developing the essential skills I still needed for the future.

Specifically, I participated in building the **Cloud Nexus** project — a network security simulation and analysis platform that allows users to design network diagrams and use AI (Google Gemini) to detect vulnerabilities, simulate attack paths, and recommend defensive measures. In this project, I was responsible for creating the architecture diagram on the Draw.io platform to describe the end-to-end workflow of the system on AWS. The diagram details each processing step: from user access to the frontend, authentication via Cognito, sending requests through API Gateway, asynchronous processing via SQS – EventBridge Pipes – Step Functions – Lambda, data storage in DynamoDB and S3, calling AI to analyze results, as well as sending alerts via SNS and logging/monitoring via CloudWatch. Through this work, I gained a clearer understanding of how serverless components on AWS work together in a real system, and how to present data flows and processing flows in a visual, easy-to-understand way.

Throughout my internship at the company, I always strove to complete assigned tasks well, complied with company regulations, and proactively engaged with colleagues and peers to improve work efficiency and quality.
