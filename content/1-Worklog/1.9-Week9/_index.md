**Wednesday & Thursday & Friday:**

- **Final semester project idea:** Create a website for designing, evaluating, and simulating network attacks.
- **Idea description:**
  - The system allows users to design computer network models using natural language through Generative AI.
  - Users only need to enter a simple description (prompt).
  - Example: "Design a basic enterprise network model with a Firewall protecting the system."
  - The AI will analyze the request, identify the required components, and automatically generate a complete network diagram including devices such as Router, Switch, Firewall, Server, Client, DMZ, IDS/IPS, etc., suited to the user's needs.
  - After the model is created, users can continue to edit it, assess security, and simulate network attacks on that same model.

**Key features:**

- Users enter a description in natural language to request network model design.
- AI automatically analyzes the request and generates an appropriate network diagram.
- Allows editing the model by adding, modifying, and removing network devices.
- AI checks the model's validity and provides warnings and improvement suggestions.
- Scans and detects security weaknesses in the network model.
- Proposes possible attack scenarios based on detected vulnerabilities.
- Simulates the attack process in detail and evaluates the level of impact.
- Proposes appropriate defense measures for each attack scenario.
- Allows re-simulation after deploying defense measures to evaluate protection effectiveness.

**Project objective:**

- Build a GenAI application that supports network design, evaluates model validity, detects security vulnerabilities, simulates network attack scenarios, and proposes defense solutions—helping learners, especially those who are new to networking and have no prior network knowledge, as well as network administrators, gain a deeper understanding of information security and the system's resilience against cyber threats.
